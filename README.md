# Zohar Komargodski

Source files for [zoharkomargodski.com](https://zoharkomargodski.com), a
professional academic website for Zohar Komargodski.

The site is intentionally static and is published with GitHub Pages. To update
the website, edit `index.html` or `styles.css`, replace files in `images/` or
`lectures/`, and commit the changes to the `main` branch.

## Main files

- `index.html` — page content
- `styles.css` — visual design and responsive layout
- `images/` — portrait and lecture thumbnails
- `lectures/` — downloadable lecture PDFs
- `zohar-komargodski-cv.pdf` — downloadable curriculum vitae
- `CNAME` — custom-domain configuration
